# Software Release Checklist

Before releasing a new software version:

1. Complete automated regression testing.
2. Review unresolved critical defects.
3. Verify database migration scripts.
4. Validate configuration changes.
5. Confirm rollback procedures.
6. Verify monitoring and logging.
7. Confirm dependency versions.
8. Review security vulnerabilities.
9. Obtain required release approvals.
10. Perform a post-deployment smoke test.
